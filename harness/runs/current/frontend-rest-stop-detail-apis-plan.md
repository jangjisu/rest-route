# 프론트 주유 정보 empty-state 표시 계획

## 범위

- 휴게소 상세 패널에서 `oil-info`가 없거나 비어 있어도 주유 섹션은 숨기지 않는다.
- 주유 가격, 정유사, 전화번호, 갱신일, 주유소 편의시설은 기존 fallback 문구로 표시한다.
- 음식 메뉴는 버튼 기반 진입점이라 기존처럼 메뉴가 없으면 버튼을 숨긴다.
- API path, 백엔드 DTO, route API 응답 구조는 변경하지 않는다.

## 대안과 선택 이유

- 대안 1, `hasOilInfo`를 true로 바꾼다: 상세 섹션은 보이지만 지도 팝업의 주유 태그까지 정보가 있는 것으로 표시될 수 있어 부작용이 크다.
- 대안 2, `renderOilInfo`에서만 섹션을 항상 보이게 한다: 팝업 태그 판정은 그대로 두고 상세 패널 UX만 고칠 수 있어 변경 범위가 작다.

## 결정

`renderOilInfo`에서 섹션 숨김 처리를 제거하고, 값 렌더링은 기존 fallback formatter를 그대로 사용한다.
