# 3단계: 계획 확정 및 사용자 승인

목표: 스펙 영향도 확인 결과를 계획에 반영하고, 구현 전에 접근 방법과 작업 범위를 승인한다.

이 단계에서는 다음을 확인한다.

- 계획이 스펙 확인 결과를 반영해 갱신되었는가
- 가능한 접근 방법과 trade-off를 비교했는가
- 사용자가 최종 계획을 승인했는가

역할별 계획 리뷰는 실행하지 않는다.
코드와 관련 기준 문서의 리뷰는 구현이 끝난 뒤 작업 전체에서 한 번만 수행한다.

화면(UI) 변경이 있는 작업이면, 화면 전체가 바뀔 때는 모바일/데스크톱 예상 화면을 보여주는 HTML 목업을 만들고, 화면 일부만 바뀔 때는 계획 문서에 변경 내용을 스펙으로 기록한다. 구현이 아직 필요하지 않다면 계획(및 목업)만 전달하는 것으로 이 단계를 마칠 수 있다.

이 단계를 통과하기 전에는 구현을 시작하지 않는다.
승인된 설계는 실행 가능한 작업 단위로 확정한다.
