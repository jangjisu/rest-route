# 프론트 전국유가 요약 별도 API 호출 전환 계획

## 범위

- 경로 조회는 기존 `/api/route-rest-stops` 호출을 유지한다.
- route 결과 화면의 전국 평균 유가 영역은 `/api/national-oil-prices/summary`를 별도 요청으로 조회한다.
- route API 응답의 `nationalOilPriceSummary` 필드는 프론트에서 더 이상 사용하지 않는다.
- 백엔드 DTO, API path, route 결과 목록, 비교 요약, 추천 태그, 상세 패널 API 호출 방식은 변경하지 않는다.
- 전국유가 요약 요청 실패 시 route 결과 목록은 유지하고 요약 영역만 숨긴다.

## 스펙 영향

- 내부 API 스펙 변경 없음: 이미 존재하는 `/api/national-oil-prices/summary`를 프론트에서 사용한다.
- 외부 API 스펙 변경 없음.
- 데이터/DB 변경 없음.
- 화면 구조 변경 없음: 기존 전국 평균 유가 영역에 데이터 공급 방식만 변경한다.

## 결정

전국유가 요약 전용 request 모듈을 추가하고, route 성공 렌더링 후 별도 요청을 시작한다. 요청 성공 시 요약 영역만 갱신하고, 실패/빈 상태에서는 요약 영역만 숨긴다.

## 접근 방법 비교

- 대안 1, route 응답의 `nationalOilPriceSummary`를 fallback으로 계속 사용한다: 일시적인 장애 대응은 쉬우나 프론트 의존이 남아 이후 route 응답 슬림화 여부를 테스트로 보장하기 어렵다.
- 대안 2, 별도 API 요청만 사용하고 route 응답 필드는 읽지 않는다: 요약 API 실패 시 요약 영역은 비지만 route 목록과 의존을 명확히 분리할 수 있고, 이후 백엔드 필드 제거 준비가 끝난다.

이번 작업의 목표가 route 응답 필드 제거 전 의존 제거이므로 대안 2를 선택한다.
