# 6단계: Commit

목표: 작업 브랜치에 규칙에 맞게 커밋하고, 실제로 커밋이 실행되었는지 확인한다.

Commit 단계에서는 다음을 확인한다.

- 기본 브랜치에서 커밋하려는 것은 아닌가
- staged 파일이 있거나(커밋 준비 완료), 최근 커밋 제목이 커밋 메시지 초안과 일치하는가(커밋 완료)
- 커밋 메시지 제목이 규칙에 맞는가

커밋 메시지 제목은 다음 형식을 사용한다.

```text
type: 내용
type(scope): 내용
```

허용 type은 `feat`, `fix`, `refactor`, `test`, `docs`, `chore`, `merge` 이다.

agent의 작업 범위는 작업 브랜치에 커밋하는 것까지이다.
원격 브랜치 push는 하네스가 자동으로 수행하지 않으며, 사용자가 직접 검증하고 명시적으로 요청할 때만 수행한다.
PR 생성과 기본 브랜치 병합도 사용자가 직접 수행한다.
